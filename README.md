**Project Summary:**
The main purpose of this project is to practice data cleaning techniques. In this project we convert column titles from camelcase to snakecase, breakdown and clean columns, explore the odometer and price columns, explore the date columns, and correct incorrect registration year data.

**Key Findings:**
There is a small analysis completed at the end of the project where we explore the mean price of top car brands sold on eBay. The analysis revealed that Volkswagen, BMW, Opel, Mercedes Benz, Auid, Ford, and Renault were in the top 4% of sales on eBay. Audi, Mercedes Benze, and BMW were the most expensive vehicles by brand while Renault and Opel were the cheapest. All of the 7 brands had similar mean mileage regardless of their price. 

**Datasource:**
This project works with a dataset of used cars from eBay Kleinanzeigen. EBay Kleinanzeigen is an ad webpage from the German eBay website. The dataset can be found [here](https://www.kaggle.com/datasets/sijovm/used-cars-data-from-ebay-kleinanzeigen). For the purposes of this project, dataquest.io has altered the data to give us practice cleaning datasets. This means the link provided has cleaner data than the one imported into this project. There are 50,000 rows and 20 columns in the dataset. 

**Tools Used:**
This project uses the coding language Python and the Python libraries NumPy and pandas.  

**How to Run the Notebook:**
To rerun this notebook, place the data file named ‘eBay_Car_Sales_Project.csv’ into the same folder. Due to the dataset used in the project containing randomly selected rows, and altered data, the results may differ.
